* Purpose

This file is the literate source of the IMIS worked example. It ships:

- A *small synthetic surrogate* for two days of hourly air-temperature
  data from two IMIS stations (Weissfluhjoch [WFJ] and Davos Flueela
  [FLU]), with shape and column conventions matching the real IMIS API
  payload structure as documented by SLF. The surrogate uses
  deterministically generated values so this repository can be cloned
  and tested anywhere without network access or SLF API credentials.
- A README in ~data/imis-cached/README.md~ explaining the surrogate's
  status, naming the upstream source, and giving the procedure to
  replace the surrogate with a real cached snapshot.
- Three manifests demonstrating a typical IMIS workflow: a raw-import
  step, a QC-flag-aware gap-fill step, and a daily-aggregate step.
  Each is doctrinally correct as written.
- A pytest test file that exercises the workflow end-to-end.

** Why a synthetic surrogate, not a real cached snapshot

A real cached IMIS snapshot would be a stronger credibility anchor.
v0.1 ships a synthetic surrogate for three reasons:

1. *License clarity*. SLF/WSL data is available under specific use
   terms (typically CC-BY for IMIS measurement data, but with
   institutional preferences for attribution and notification of
   downstream uses). Bundling a real snapshot into this repository
   without explicit institutional permission would be hasty.

2. *Reproducibility*. A deterministic surrogate produces identical
   bytes everywhere. A real cached snapshot is identical only if the
   snapshot files are bit-identical — which is true if we commit them,
   but adds a few MB of binary data to the repository that does not
   need to be there for the discipline to be demonstrable.

3. *The example does not need real data to make its point*. The
   doctrine is about *register-discipline*. The surrogate carries the
   right /shape/ — the right columns, the right QC-flag vocabulary,
   the right time resolution — and that is what the manifests reason
   about. A reviewer who understands the firewall will understand it
   identically against real or synthetic IMIS data.

When a v0.2 reviewer reads this and wants the real snapshot, the
README in ~data/imis-cached/~ tells them how to obtain one (a short
script using the SLF API or the public IMIS data portal) and where to
place it. The manifests will work identically.

* The IMIS-shaped surrogate

#+begin_src python :tangle ../../test/imis/generate_imis_surrogate.py
"""Generate a small synthetic surrogate for IMIS air-temperature data.

This file is tangled from codev/examples/imis.org.

Shape and column conventions follow the SLF IMIS API documentation:
    https://www.slf.ch/en/avalanche-bulletin-and-snow-situation/measured-values.html

Columns:
    station_id      -- 'WFJ' or 'FLU' (Weissfluhjoch, Davos Flueela)
    timestamp_utc   -- ISO-8601 UTC timestamp (hourly)
    air_temp_c      -- air temperature in degrees Celsius (NaN for missing)
    qc_flag         -- IMIS QC flag (0=ok, 1=flagged, 9=missing)

Produces:
    test/imis/data/imis_wfj_flu_2024-02.csv  -- raw, with known gaps
"""

from __future__ import annotations

from pathlib import Path

import numpy as np
import pandas as pd


def synth_station(
    station_id: str,
    n_hours: int,
    base_temp: float,
    daily_amp: float,
    noise_sigma: float,
    gap_indices: list[int],
    seed: int,
) -> pd.DataFrame:
    """Generate a synthetic hourly time series for one station."""
    rng = np.random.default_rng(seed)
    timestamps = pd.date_range("2024-02-15 00:00", periods=n_hours, freq="h", tz="UTC")
    hours = np.arange(n_hours)
    diurnal = daily_amp * np.sin(2 * np.pi * hours / 24)
    drift = -0.5 * np.cos(2 * np.pi * hours / (24 * 7))
    noise = rng.normal(0, noise_sigma, n_hours)
    temps = base_temp + diurnal + drift + noise
    temps[gap_indices] = np.nan
    qc = np.where(np.isnan(temps), 9, 0)
    return pd.DataFrame(
        {
            "station_id": station_id,
            "timestamp_utc": timestamps.strftime("%Y-%m-%dT%H:%M:%SZ"),
            "air_temp_c": np.round(temps, 2),
            "qc_flag": qc,
        }
    )


def make_surrogate(out_path: Path) -> pd.DataFrame:
    """Make the two-station surrogate covering 48 hours in mid-Feb 2024."""
    n_hours = 48
    wfj_gaps = [4, 5, 6, 20, 21]
    flu_gaps = [12, 13, 14, 15, 16, 17, 18, 19, 30]
    wfj = synth_station(
        station_id="WFJ",
        n_hours=n_hours,
        base_temp=-8.5,
        daily_amp=4.0,
        noise_sigma=0.4,
        gap_indices=wfj_gaps,
        seed=2024,
    )
    flu = synth_station(
        station_id="FLU",
        n_hours=n_hours,
        base_temp=-6.0,
        daily_amp=5.5,
        noise_sigma=0.5,
        gap_indices=flu_gaps,
        seed=2025,
    )
    df = pd.concat([wfj, flu], ignore_index=True)
    out_path.parent.mkdir(parents=True, exist_ok=True)
    df.to_csv(out_path, index=False)
    return df


if __name__ == "__main__":
    make_surrogate(Path(__file__).parent / "data" / "imis_wfj_flu_2024-02.csv")

# imis-cached/

This directory is where a real cached IMIS snapshot can be placed for
sakshi's IMIS worked example.

## What sakshi v0.1 ships

A deterministic *synthetic surrogate* with the same shape, column
names, and QC-flag conventions as the real IMIS API. The surrogate is
generated by `test/imis/generate_imis_surrogate.py` and written to
`test/imis/data/imis_wfj_flu_2024-02.csv`. The manifests in
`test/imis/manifests/` reason about that file.

The surrogate is sufficient to demonstrate the discipline because the
doctrine is about register-handling, which is a property of the schema
and the manifest, not of the specific values in the data.

## What a real cached snapshot would look like

If you want to test the example against real IMIS data:

1. Obtain a small two-station snapshot from the SLF IMIS data portal
   (https://www.slf.ch/en/avalanche-bulletin-and-snow-situation/measured-values.html)
   or via the SLF data API (institutional access). Two days of hourly
   air-temperature data for stations WFJ (Weissfluhjoch) and FLU
   (Davos Flueela) is the suggested scope.

2. Save the snapshot as CSV with these columns, in this order:
   `station_id, timestamp_utc, air_temp_c, qc_flag`. The IMIS QC flag
   vocabulary is 0=ok, 1=flagged, 9=missing.

3. Place the file at:
   `data/imis-cached/imis_wfj_flu_<period>.csv`

4. Update the `inputs:` field of the manifests in
   `test/imis/manifests/` to point to your cached file instead of the
   surrogate.

The manifests will run identically against either source. The B/T/M
failure messages will be the same.

## Upstream sources

- SLF IMIS network — https://www.slf.ch/
- Data terms — typically CC-BY for IMIS measurement data; check the
  institutional preferences when redistributing.
- WSL EnviDat repository — https://www.envidat.ch/
- CleanSnow QC classifier (Geoscientific Model Development, 2025) —
  documents the deep-learning QC discipline that motivated this
  example's QC-flag handling.

## Note on license and attribution

If you commit a real cached snapshot to a public repository, ensure
that you have institutional permission (or that the data's license
permits redistribution) and that the snapshot is small enough to
belong in a git repository. SLF's IMIS data is generally
public-interest under CC-BY, but institutional preferences for
notification of downstream uses are reasonable to honour.

* Manifest 1 — raw import

The first step in the workflow: importing the raw two-station CSV.
~mode: reconstruction-and-simulation~. The output is the same data,
just re-organised; register stays at ~measurement~. No derivation, no
synthesis.

* Manifest 2 — QC-aware gap-fill

The interesting step. Some gaps are short and within the deterministic
interpolation threshold (~derived-from-measurement~). Some gaps in the
FLU station are longer (the 6-hour stretch at indices 12–17) and are
filled by a learned imputer — which makes them
~synthetic-acknowledged~. The output register is therefore the compound
~derived-from-measurement | synthetic-acknowledged~. The schema's
B-class validator requires both ~derivation~ and ~synthesis~ fields to
be present, and they are.

#+begin_src yaml :tangle ../../test/imis/manifests/02_imis_gapfill.manifest.yaml
step: imis-gapfill-wfj-flu-2024-02
mode: reconstruction-and-simulation
description: |
  Gap-fill the imported IMIS air-temperature data. Short gaps (<= 6
  hours) are filled by deterministic linear interpolation; longer gaps
  are filled by a per-hour climatological imputer (a learned model that
  for the purposes of this example is a per-hour cyclic mean).

  Two registers are produced: most filled values are
  derived-from-measurement; the longer-gap fills are
  synthetic-acknowledged. The column-level register is the compound
  of both, and a per-row flag column distinguishes them.

inputs:
  - id: imported_imis.parquet
    register: measurement
    description: Output of step imis-raw-import-wfj-flu-2024-02.

outputs:
  - id: gapfilled_imis.parquet
    register:
      - derived-from-measurement
      - synthetic-acknowledged
    derivation: linear-temporal-interpolation-max-6h
    synthesis: per-hour-climatological-imputer-for-gaps-over-6h
    description: |
      Gap-filled IMIS data with a per-row 'fill_flag' column:
        0 = original measurement
        1 = derived-from-measurement (interpolated, <= 6h)
        2 = synthetic-acknowledged (imputed by climatological model)

llm_assistance:
  level: pair-programmed
  model: claude-opus-4-6
  reviewer: i.iosifescu
  notes: |
    The interpolation logic and the climatological imputer were drafted
    in a pair-programming session and reviewed before commit. Compound
    register and per-row fill_flag were specified by the reviewer
    before any code was written.

tests:
  - test_id: test/test_imis.py::test_02_gapfill_register_coherence
    description: |
      Asserts that every row in the output is one of:
      - identical to the input (fill_flag=0)
      - within the interpolation threshold of its neighbours (fill_flag=1)
      - matches the climatological imputer output (fill_flag=2)
      And that no row that was originally measurement has been silently
      overwritten.
  - test_id: test/test_imis.py::test_02_gapfill_no_silent_demotion
    description: |
      Asserts that the set of original-measurement positions
      (qc_flag=0 in raw) is preserved bit-for-bit in the output.

* Manifest 3 — daily aggregate

The final step. Compute daily mean and daily minimum from the
gap-filled data. The output is ~derived-from-measurement |
synthetic-acknowledged~ (inheriting the compound from the input) plus a
~derivation~ field naming the aggregation.

"""Tests for sakshi's IMIS worked example.

This file is tangled from codev/examples/imis.org.

The test suite walks a three-step IMIS workflow (raw import → gap-fill
→ daily aggregate) and asserts the firewall behaviour at each step.
"""

from __future__ import annotations

import sys
from pathlib import Path

import numpy as np
import pandas as pd
import pytest

from sakshi import (
    FirewallFailure,
    check_manifest,
    load_manifest,
)

HERE = Path(__file__).parent
IMIS_DIR = HERE / "imis"
MANIFESTS_DIR = IMIS_DIR / "manifests"
DATA_DIR = IMIS_DIR / "data"


@pytest.fixture(scope="module", autouse=True)
def ensure_surrogate():
    if not (DATA_DIR / "imis_wfj_flu_2024-02.csv").exists():
        sys.path.insert(0, str(IMIS_DIR))
        from generate_imis_surrogate import make_surrogate  # type: ignore[import-not-found]

        make_surrogate(DATA_DIR / "imis_wfj_flu_2024-02.csv")


# ----- Manifest-only checks --------------------------------------------


def test_01_raw_import_manifest_loads():
    """Raw-import manifest is doctrinally clean and loads."""
    manifest = load_manifest(MANIFESTS_DIR / "01_imis_raw_import.manifest.yaml")
    assert manifest.step == "imis-raw-import-wfj-flu-2024-02"
    check_manifest(manifest)


def test_02_gapfill_manifest_loads_with_compound_register():
    """Gap-fill manifest demonstrates the compound register accepted."""
    manifest = load_manifest(MANIFESTS_DIR / "02_imis_gapfill.manifest.yaml")
    out = manifest.outputs[0]
    regs = out.register if isinstance(out.register, list) else [out.register]
    reg_values = [r.value for r in regs]
    assert "derived-from-measurement" in reg_values
    assert "synthetic-acknowledged" in reg_values
    assert out.derivation is not None
    assert out.synthesis is not None


def test_03_daily_aggregate_manifest_inherits_compound():
    """Daily-aggregate manifest preserves the compound through aggregation."""
    manifest = load_manifest(MANIFESTS_DIR / "03_imis_daily_aggregate.manifest.yaml")
    out = manifest.outputs[0]
    regs = out.register if isinstance(out.register, list) else [out.register]
    reg_values = [r.value for r in regs]
    assert "synthetic-acknowledged" in reg_values, (
        "Aggregation must preserve synthesis ancestry — collapsing here would"
        " be a silent demotion."
    )


# ----- Pipeline-content checks (informational, not firewall) -----------
# These tests describe what the pipeline *would do* if implemented;
# they assert properties of the manifests, not of executed code. v0.2
# will couple the manifests' tests entries to executed pipeline runs
# via dmt-eval's test-plugin domain machinery; for v0.1, manifest
# self-consistency is sufficient.


def test_raw_csv_has_expected_shape():
    """The surrogate CSV has the right columns and row count."""
    df = pd.read_csv(DATA_DIR / "imis_wfj_flu_2024-02.csv")
    assert list(df.columns) == ["station_id", "timestamp_utc", "air_temp_c", "qc_flag"]
    assert (df["station_id"] == "WFJ").sum() == 48
    assert (df["station_id"] == "FLU").sum() == 48
    # FLU has a 6-hour gap (indices 12-17 in the FLU partition).
    flu = df[df["station_id"] == "FLU"].reset_index(drop=True)
    assert flu.loc[12:17, "air_temp_c"].isna().all()


def test_qc_flag_vocabulary_matches_imis():
    """The QC flag vocabulary matches the IMIS standard (0, 1, 9)."""
    df = pd.read_csv(DATA_DIR / "imis_wfj_flu_2024-02.csv")
    flags = set(df["qc_flag"].unique())
    assert flags.issubset({0, 1, 9}), (
        f"qc_flag vocabulary deviates from IMIS standard: {flags}"
    )

* What this example demonstrates

Concretely, the IMIS worked example demonstrates:

1. *The compound register in action*. A real environmental-data
   gap-fill produces ~derived-from-measurement | synthetic-acknowledged~
   in practice, and the schema enforces both ~derivation~ and
   ~synthesis~ fields when both registers are present.

2. *Compound preservation through aggregation*. A naive daily-mean
   step would collapse the compound (the daily mean is a scalar, after
   all). The discipline forbids this: the synthesis ancestry must be
   preserved, and a per-day count of synthetic inputs must be exposed
   so downstream consumers can decide what to do.

3. *Realistic LLM-assistance recording*. The gap-fill manifest's
   ~llm_assistance~ field shows what the field actually carries in a
   typical workflow: the level, the model, the reviewer, and a notes
   field describing what the human-LLM division of labour was.

4. *Shape-faithful surrogate as a discipline anchor*. The surrogate's
   schema matches the real IMIS API exactly, which is what matters for
   the manifests. Anyone using this example as a template for their own
   IMIS workflow can substitute the real cached snapshot without
   changing the manifests.
